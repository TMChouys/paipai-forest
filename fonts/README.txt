NotoSansTC.ttf = Noto Sans TC (Variable), Google / Adobe, SIL Open Font License 1.1
https://fonts.google.com/noto/specimen/Noto+Sans+TC  ·  https://openfontlicense.org
網頁版沒有系統中文字型，所以遊戲內附這個字型。

CascadiaMono.ttf = Cascadia Mono (Variable), Microsoft, SIL Open Font License 1.1
https://github.com/microsoft/cascadia-code
程式碼區用的等寬字型；中文字會退回 Noto Sans TC。
body.tres / bold.tres / mono.tres 指定可變字型的粗細（400 / 700 / 400），
因為 Noto Sans TC 不指定時是最細的 100。
