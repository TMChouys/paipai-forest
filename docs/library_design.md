# 派森圖書館：場景設計稿（草稿，待確認）

> 圖書館是一個新的場景，跟家（樹屋）一樣分三層：**外圍 → 主建物 → 可以走進去的內部**。
> 從鎮中心北邊的圖書館大門進來。整體是一座**很老、很高、很多層的教堂**，有中古世紀到文藝復興的味道。

## 1. 外圍（進門前）

```
                 （北）
        ┌───────────────────────────┐
        │   高聳的教堂主體（見第 2 節） │
        │      ▲鐘塔        ▲鐘塔      │
        └──────────┬─大門─┬──────────┘
          石獅子      寬寬的石階（5 階）    石獅子
      常春藤牆                           常春藤牆
   ┌──────────── 石板前庭 ────────────┐
   │  老橡樹   長椅      長椅   老橡樹  │
   │      花圃        日晷       花圃   │
   └────────── 鐵門（拱形門框）─────────┘
                 （南：回鎮中心）
```

- **前庭**：鋪著磨圓的舊石板，石縫長青苔；兩棵很老的橡樹、兩張長椅、中間一座**日晷**（呼應「時間、慢慢來」）。
- **鐵門**：拱形、鐵花紋，上面掛著「派森圖書館」的木牌；從這裡走回鎮中心。
- **石階**：寬寬五階，兩邊一對石獅子（或石頭烏龜）守門。
- 牆上爬滿常春藤，有一兩塊石頭剝落，看得出年代很久。

## 2. 主建物（從外面看）

- 灰白色、帶一點暖黃的石頭；**非常高**：正面是一大片山牆，中間一扇**大圓花窗**（彩色玻璃），兩側各一座尖頂鐘塔。
- 外牆有一排排的**尖拱窗**，看得出至少 **四層樓**；屋頂是深色石板瓦，尖頂上有小小的風向雞。
- 大門：兩扇很厚的木門、鐵鉚釘、門上方半圓形的浮雕（一本打開的書）。
- 鏡頭往上看時，塔尖會超出畫面，營造「好高、好老」的感覺。

## 3. 內部

   │            ┌─────────────────────┐            │

   │            │  大書桌、地球儀、燭台、   │            │

### 大廳（中間）
- 一進門就是挑高的大廳，**抬頭看得到上面二、三、四樓的迴廊和書櫃**（上不去，只是背景，顯得很高）。
- 地板是**淺色石磚格子**（和家裡一樣用格子座標，之後的任務可以在大廳進行）。
- 正中央一座**哲學家雕像**：石頭雕的老烏龜，一手捧書、一手指著天空（想事情的樣子），底座刻一句話。
- 天花板是拱頂，掛幾盞大吊燈（燭台式）；陽光從花窗斜斜照進來，地上有彩色光斑。

### 借書櫃台（大廳最裡面）
- 長長的木頭櫃台，上面有借書卡盒、印章、一疊書、一盞綠色檯燈、一個小鈴鐺。
- 之後「借書紀錄」（檔案讀寫）、「找書」（搜尋）的任務可以在這裡。

### 館長室（櫃台後面的加高平台）
- 不是房間，是**開放的平台**，比大廳高三階，有木欄杆。
- 大書桌（攤開的書、羽毛筆、墨水瓶）、地球儀、燭台、高背椅、背後一排矮書櫃。
- **慢慢館長平常就在這裡**。玩家走到平台前跟他說話，就能讀他的書、上課。

### 樓梯（櫃台後面）
- 寬寬的石頭樓梯往上層，入口用**紅龍（紅絨繩柱）**圍起來，掛一塊小牌「整理中，暫不開放」。
- 之後新章節開放，可以拆掉紅龍上二樓。

### 閱讀教室（大廳左邊）
- 三張長木桌、長椅、桌上的讀書燈，牆上一塊小黑板。
- 這裡是「上課」的地方：館長或派派兔帶著讀書，照「看 → 猜 → 改 → 寫」一步一步來。

### 書櫃區（大廳右邊）
- 一排排頂到天花板的高書櫃、可以滑動的梯子、窗邊一張閱讀椅。
- 書櫃照章節排（第 1 章、第 2 章…），**學過的概念書會亮起書背**，沒學過的灰灰的。

### 規則
- **圖書館裡的擺設玩家都不能移動**（和家裡不同）：點了只會有說明或對話，不會進入搬家具模式。

## 4. 角色
- 慢慢館長：館長室平台。
- 派派兔（兔兔學姊）：有時候在閱讀教室幫忙（她是館長的學徒）。

## 5. 目前的做法（第二版）
- **規模**：世界奇觀等級。室內 26×32 公尺（大廳挑高 24 公尺，二、三、四樓迴廊），兩座 36 公尺的鐘塔加尖頂、中央大圓頂、兩側飛扶壁；前庭是 44×28 公尺的大廣場，四周圍著石牆。
- **鏡頭**：和家裡差不多近，顯得建築很大；派派鼠走路時鏡頭跟著。
- **走路**：圖書館裡和前庭都可以點地板讓派派鼠走過去（0.5 公尺一格的找路網格，會繞過家具、走上館長平台的樓梯）。不能去的地方用石牆圍起來：前庭四周、平台兩側；往上層的樓梯用紅龍擋住。
- **怎麼進出**：鎮中心點圖書館的門 → 前庭；點大門走進大廳；大廳點大門回前庭；前庭點鐵門回鎮中心。
- **館長平台**：比借書櫃台遠，高八階，前面一道寬樓梯。
- **派派兔**：在借書櫃台打工。在圖書館點她不會給提示，會請你去問館長。
- **雕像**：初代大賢者，慢慢館長的老師，派派森林知識的起源。
- **點館長**：打開「慢慢館長的課」（scripts/ui/lesson_book.gd）。左邊照知識地圖 A～K 分類，右邊一課五步：要學什麼 → 你知道嗎？ → 講解 → 選擇練習 → 相關任務。
  課文在 data/curriculum/lessons.json，由 tools/curriculum/gen_lessons.py 產生（範例都會真的執行一次，執行結果是跑出來的）。
- **格子地板**：整層都是石磚格子，任務用的格子區是櫃台前面 8×6 格（金色細框）。
- 程式：scripts/world/library_view.gd
