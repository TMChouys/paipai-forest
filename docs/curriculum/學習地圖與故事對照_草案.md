## 一、設計原則

1. **一次一個概念，由簡到難**：每個概念都有先備概念，先備沒學會，下一個就「還沒到貨」（✅ 雜貨店商品＝知識地圖）。
2. **每個概念都有形成性評量，分三種角色**（✅ 教學分工）：

   | 誰 | 評量什麼 | 形式 | 通過標準（💡） |
   |---|---|---|---|
   | 慢慢館長 | **認知**：懂不懂、會不會預測結果 | 選擇題：記憶 → 理解 → 預測輸出（每概念 2～3 題，班級版再加課本習題） | 答對才算「讀懂這一課」 |
   | 派派狼 | **實作**：寫不寫得出來 | 委託任務，依階段打分：① 能執行（沒有語法錯誤）② 輸出正確 ③ 用到指定的概念 ④ 寫得簡潔好讀 | ★ 1～3；**★2 以上**才送貨、解鎖下一個商品 |
   | 派派兔 | 不打分數，**卡住時給提示** | 三層提示：方向 → 關鍵語法 → 差一步的範例；第三層就請你去問館長 | — |

3. **每一章的結尾有一個「複合任務」**（同時用到這一章 2～4 個概念）＝這一章的**總結性評量**，完成後打開**爺爺箱子的一道鎖**（✅ 鎖著的箱子，每學完一個範圍開一道）。
4. **獎勵循環**（✅）：老闆娘有事 → 委託派派狼 → 派派鼠寫程式 → 派派狼評分 → 老闆娘送家具到家。
   基礎的貨（單一概念任務）送一般家具；**進階的貨（複合任務）要工匠用基礎的貨做**，送比較特別的家具。

## 三、故事主線（2026-11-08 討論後）

**✅ 已確認**
- **爺爺和慢慢館長是老朋友、冒險夥伴**：爺爺愛冒險，館長愛讀書，就像現在的派派狼和派派兔。
- **結局是「傳承的告別」**：爺爺已經不在了，箱子裡是留給派派鼠的祝福和「最後一課」。
- **拉布拉多老闆娘取代狸老闆**：原本狸老闆的市集任務（會員卡、購物清單、價目表）都改成老闆娘的。
- **加入工匠（河狸木匠）和寶庫守門人**：每一章都要有戲份，不能只為一條支線出現。人物細節和模型之後再調整。

**💡 串起整條故事的建議：「三個老朋友 → 三個新朋友」**
- 很久以前，**爺爺（地鼠）、慢慢館長（陸龜）、寶庫守門人（貓頭鷹）**是一起冒險的三個老朋友。
  他們在螢光寶庫最深處藏了一樣東西，約好「等下一個愛冒險的孩子來了再打開」。
- 現在，**派派鼠、派派狼、派派兔**是新的三人組，一步一步走過爺爺他們當年走過的路。
- 河狸木匠的師父當年和爺爺一起蓋了這間樹屋，所以木匠手上有一本「樹屋的家具清單」。
- 告別的語氣要溫和：館長在第 10 章輕輕說出爺爺已經不在了；最後一課的意思是「你已經會用自己的話，說出自己的故事了」。
  派派鼠在筆記本最後一頁寫下自己的第一句話，傳承下去。
