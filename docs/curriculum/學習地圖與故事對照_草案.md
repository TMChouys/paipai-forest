## 一、設計原則

1. **一次一個概念，由簡到難**：每個概念都有先備概念，先備沒學會，下一個就「還沒到貨」（✅ 雜貨店商品＝知識地圖）。
2. **每個概念都有形成性評量，分三種角色**（✅ 教學分工）：

   | 誰 | 評量什麼 | 形式 | 通過標準（💡） |
   |---|---|---|---|
   | 慢慢館長 | **認知**：懂不懂、會不會預測結果 | 選擇題：記憶 → 理解 → 預測輸出（每概念 2～3 題，班級版再加課本習題） | 答對才算「讀懂這一課」 |
   | 派派狼 | **實作**：寫不寫得出來 | 委託任務，依階段打分：① 能執行（沒有語法錯誤）② 輸出正確 ③ 用到指定的概念 ④ 寫得簡潔好讀 | ★ 1～3；**★2 以上**才送貨、解鎖下一個商品 |
   | 派派兔 | 不打分數，**卡住時給提示** | 三層提示：方向 → 關鍵語法 → 差一步的範例；第三層就請你去問館長 | — |

3. **每一章的結尾有一個「複合任務」**（同時用到這一章 2～4 個概念）＝這一章的**總結性評量**，完成後打開**爺爺箱子的一道鎖**（✅ 鎖著的箱子，每學完一個範圍開一道）。
4. **獎勵循環**（✅）：老闆娘有事 → 委託派派狼 → 派派鼠寫程式 → 派派狼評分 → 老闆娘送家具到家。
   基礎的貨（單一概念任務）送一般家具；**進階的貨（複合任務）要工匠用基礎的貨做**，送比較特別的家具。
