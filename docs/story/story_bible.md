## 一、世界：派森小鎮

派森小鎮（Python Town）是一個住著動物居民的小鎮。

**小鎮的魔法**：小鎮被一種古老的魔法包圍，只有用 Python 說的話，大家才聽得懂。
用 `print()` 才能把話說出口，用 `input()` 才能聽懂別人的問題。
學得越多，魔法越強，能和越多居民交流、去越遠的地方。

**這個世界**：派派森林、薰衣草原、螢光寶庫是這個世界裡的不同地方。
舊故事裡的「派森地下城」，是到這些地方的地底冒險的統稱。
**這個遊戲不打怪，所以沒有派森地下城了。** 學習任務都由小鎮居民在日常互動中交給派派鼠。

派派森林、薰衣草原、螢光寶庫在小鎮周圍；鎮中心在森林外面。

**遊戲裡的鎮中心**（`scripts/world/town_view.gd`，樹屋按「去鎮上」）：圓形石板廣場，中間噴水池；
北邊圖書館（藍綠屋頂、圓窗、門口一疊書，慢慢館長站在台階前）、西邊郵局（紅屋頂、山牆上的大信封、門前紅郵筒，拍拍鳥在附近）、
東邊狸老闆的雜貨攤（紅色攤棚、橡實／胡蘿蔔／蘋果、價目表小黑板）、任務公告欄、路燈，南邊的石頭小路和「往派派森林」路牌。
點居民會聊天（台詞在 town_view.gd 的 LINES）。
鎮上的任務（支線，完成 D01 後解鎖；居民頭上有「！」，點居民接任務，點任務公告欄打開任務書）：
- 拍拍鳥〈郵局前的合照〉（一行一個 print）→ 獎勵「郵局前的合照」
- 狸老闆〈市集的會員卡〉（變數）→ 獎勵「橡實糖罐」

任務 JSON 的 room 寫 "scene": "town" 和 "spot"（post_office / market / library），任務就在那棟房子前面進行。派派鼠一開始就能去鎮中心：開場後派派兔帶派派鼠逛過鎮上，認識大家。

## 二、角色

### 教學分工（2026-11-08 使用者確認）
| 角色 | 教學上做什麼 | 怎麼教 |
|---|---|---|
| 派派狼 | **實作與評量**：檢測會不會寫 | 發實作任務（多半是幫雜貨店老闆跑腿的委託），依程式的各個階段評分 |
| 派派兔（學姊） | **同儕指引**：卡住時給小提示 | 一兩句提示、一個小例子；要深究學問就說「去問館長喔」 |
| 慢慢館長 | **最完整的知識**：講解最細 | 圖書館的「慢慢館長的課」：講解、範例、執行結果，加上認知的選擇題測驗 |

**獎勵循環**：雜貨店老闆有事要辦 → 委託給派派狼 → 派派狼交給派派鼠做（實作任務）→ 做完了，老闆把**家具送貨到派派鼠家**當謝禮。
派派鼠的家一開始是空的，只有滿地灰塵、要先掃一掃，連地毯都沒有；家具是一件一件靠派派狼的任務慢慢累積來的。
- 遊戲裡（2026-11-08）：新玩家的收藏冊是空的。完成第一個委託〈嘿！新來的〉，雜貨店老闆送來「蘑菇小燈」，順便把「編織圓地毯」鋪好；
  之後每完成一個委託，老闆就送一件家具到家（完成畫面寫「雜貨店老闆送貨到家：『○○』！」）。舊存檔的家具、地毯不變。

**雜貨店的商品清單＝知識地圖**（2026-11-08 使用者確認）：
- 商品照知識地圖分類，分「基礎」和「進階」；先學、後學的關係就是商品的先備關係。
- 先備任務還沒完成時，進階任務是鎖住的，店裡說成「**這個商品還沒到貨**」。
- 要先有基礎的貨，工匠廠商才能用它做出進階家具。所以先完成基礎任務，進階家具才會到貨。
- 遊戲裡（2026-11-08）：**小鎮場景先不用**。上方功能選單有「圖書館」和「雜貨店」：圖書館直接到前庭（鐵門、「回樹屋」按鈕回家）；
  雜貨店先做成商品清單（scripts/ui/store_book.gd）：左邊貨架是知識地圖 A～K，右邊商品分基礎（★～★★）和進階（★★★ 以上），
  狀態有「有貨！去找派派狼接委託」「工匠還在做（委託準備中）」「還沒到貨：要先有〇〇的貨」「已經送到家了」。

### 派派鼠（主角，玩家操作）
- 從外地來到派森小鎮的新居民，帶著行李和爺爺給的舊照片（照片上是大樹底下的樹屋），照著照片找到這裡。
- 剛搬進派派森林樹屋的新居民，一開始還不會用 Python 說話（開場只會「……？」）。
- **為什麼搬來**：樹屋原本是派派鼠家人的，派派鼠繼承了它。屋裡有家人的舊筆記和一個**鎖著的箱子**。
- 個性：好奇、有點害羞，學會一句就很開心。
- 會走路、搬家具、坐、睡、看書。

### 派派狼
- 紅圍巾，很好認。嘴硬心軟：說「勉強收你當小弟」，其實會幫忙提背包、在岔路口等人。
- 是**發任務的人**（派派狼的任務板／任務書）。帶路去派派森林、薰衣草原、螢光寶庫。
- **教學上的角色：實作與評量**。派派狼常常接下雜貨店老闆的委託，再交給派派鼠去做；派派鼠寫程式，派派狼一個階段一個階段地檢查、打分數。
  完成委託後，老闆就把家具送到派派鼠家。
- 口頭禪：「嘿！新來的」「跟著我混」「再試一次就好，誰第一次就什麼都會？」
- 重視：看路、帶水、記得回家的方向、不逞強。

### 派派兔（兔兔學姊）
- **草藥學徒**：**半年前**從外地來到派派森林，跟著慢慢館長學習草藥的知識。比派派鼠早來一些，可以叫她兔兔學姊。
- 平常在圖書館打工；**沒有排班的時候都跟著派狼老大冒險**（她叫派派狼「派狼老大」）。
- **在圖書館的借書櫃台打工**：會給一句小提示，但要學完整的就請派派鼠上樓梯去問館長。
- 圓眼鏡，背包裡有葉子和小筆記本。
- **教學上的角色：同儕指引（學姊嘛～）**。派派鼠卡住時，派派兔用自己剛學會的經驗給一兩句提示、一個小例子；
  要學完整、有結構的知識，派派兔會說「這個要去圖書館問館長喔」。
- 喜歡讀書、照顧植物（胡蘿蔔園、薰衣草原），會對小苗說話。
- 曾經把回家的岔路記反，後來學會畫小地圖：**犯過的錯會變成下一次的提醒**。
- 常替派派狼翻譯他不擅長表達的關心。
- 愛吃紅蘿蔔卻戴眼鏡：她說可能是讀書忘記休息了——保護眼睛除了營養，更重要的是適當休息（剛從草藥學的書裡學到的）。
  派派鼠做完第一個任務、會用 print() 說話以後，點派派兔有機會聽到這段（main.gd 的 RABBIT_STORIES）。

### 拍拍鳥
- 炭藍色的烏鴉，苔綠圍巾、亞麻背心，帶著木頭風箱相機。
- 小鎮的郵差兼攝影師：每週寄一張冒險照片來（派派森林、薰衣草原、螢光寶庫各 6 張），也負責送信。
- 個性：**話多、愛八卦**。到處飛，什麼消息都知道；送信時順便講小鎮新聞，常帶來新任務的線索。
- 適合的任務：照片編號、相簿清單、信件、排序。
- 關係：和派派狼、派派兔是**從小認識的老朋友**，常鬥嘴。拍拍鳥愛講派派狼的糗事，派派狼嘴硬反駁，派派兔在旁邊笑。

### 慢慢館長（圖書館館長・派派兔的老師）
- 很老很老的陸龜，鎮中心圖書館的館長，也是**派派兔的老師**（派派兔是他的草藥學徒）。什麼都慢慢來，所以大家叫他慢慢館長。
- **樣子像哲學家**：下巴垂著長長的白鬍子、白色長眉毛，小圓眼鏡掛在鼻尖；奶油色長袍、外面披著金邊的紫色披風；
  拄著彎彎的木頭拐杖，腋下夾著一本厚書。皮膚帶一點綠，背著一個又大又重的龜殼。
- 走路很慢、很小心：步子小小的，一步一步拄著拐杖走。
- 個性：說話很慢、很溫和；**喜歡用問題回答問題**——「你覺得呢？」「如果把 3 改成 5，會怎樣？先猜猜看。」
  口頭禪：「慢慢來，比較快。」「先猜，再看。」
- **教學上的角色：完整、有結構的知識**。圖書館裡一個概念一本書，照章節排在書櫃上；讀書照「看 → 猜 → 改 → 寫」一步一步來。
  派派兔給的是簡單提示，真正要弄懂就來找館長。
- **知道派派鼠家人以前的事**：2026-11-08 確認，**館長和爺爺是老朋友、冒險夥伴**（爺爺愛冒險、館長愛讀書，就像現在的派派狼和派派兔）。
  館長慢慢透露鎖著的箱子的線索；第 10 章由館長溫和地說出爺爺已經不在了。
- 適合的任務：借書紀錄（檔案讀寫）、找書（搜尋）。
- **在圖書館點館長，會打開「慢慢館長的課」**：一課只教一個概念，照課本章節、依知識地圖分類；
  每課五步：這一課要學什麼 → 你知道嗎？（先提問）→ 講解（範例＋執行結果）→ 選擇練習（對答案）→ 相關任務。

這個版本**只做森林信箱**（和信件、檔案任務最有關係）：藍色圓頂、木柱、紅色小旗、門縫露出一封信，是拍拍鳥送給派派鼠的見面禮。信箱**固定在屋外門口旁邊（門的東邊，離屋子一格）**，不是屋裡可以搬動的家具。派派狼和派派兔是來拜訪的，平常站在門口正對面的小石路上、面向門，等派派鼠。

樹屋的樣子：外牆是一根根帶樹皮的圓木，四個牆角是樹幹（後面兩根比較高、頂上長葉子），牆頂長青苔、南牆垂著藤蔓、牆腳有小紅蘑菇；樹屋背靠一棵像神木一樣的巨大老樹（好幾根樹幹長在一起、板根張開、樹冠又高又寬）。門是長方形的木板門。

樹屋這張地圖（2026-11-07 依舊 2.5D 版重新配置）：樹屋變大（10x9），**前院**很大（泥土地、矮木柵欄、南邊柵欄門口、東邊的胡蘿蔔園、東南角的大蘑菇、門口小石路一直延伸到柵欄外，信箱在柵欄門口旁）、**溪流**從樹屋西邊旁流過（南北向，有小瀑布），西邊柵欄留一個缺口通到**溪畔釣魚角**（岸上的小木平台、水桶）。屋裡有圓窗；北牆有**往天空樹頂的門**（樹幹上的橢圓門洞，裡面塞滿石頭，外面釘三塊木板，前面堆著木箱，掛著「暫時封閉」）。
第一次見面（開場在門口，或之後第一次走過去說話）——派派狼（2026-11-08 改）：「嘿！新來的，看你的家空空的，我教你怎麼打工拿獎勵。」（派派鼠：「……？」）「........怎麼不說話？」「喔！你是不會用表達式 print() 吧！」「我看你甚麼都不會的樣子，沒關係！以後跟著我混，我教你！」派派兔（2026-11-08 改）：「你好呀！我是派派兔。半年前才來到派派森林，跟著慢慢館長學習草藥的知識，平常會在圖書館打工。沒有排班的時候都跟著派狼老大冒險。你也可以叫我兔兔學姊，以後就跟著我們一起冒險吧！」之後點派派狼、派派兔，派派鼠會先走到旁邊才說話：**派派狼給任務**（打開任務板），**派派兔管任務書**（打開「派派兔的任務書」，再給一句小提示）。爺爺的照片寫著「派派森林・大樹下的樹屋」，這間屋子在派派森林裡。
**這張地圖就是派派森林**：樹屋四周都是樹，一直到地圖邊緣。前院很大（往東、往南都拓寬了）。小石路從門口穿過柵欄小門，變成彎彎的森林小徑往南，一直通到森林邊緣的路牌「往派森小鎮」；派派鼠走到那裡就是出遠門去小鎮（上方的「出遠門」按鈕也是讓派派鼠沿著小徑走出去）。柵欄小門平常關著，有人經過才打開。
前院的柵欄整圈圍起來：從房子兩側的轉角接出去，南邊是關著的柵欄小門，西邊圍出一個小凹口到溪邊的釣魚平台；柵欄外面不能走。派派狼和派派兔也會擋路，派派鼠會繞過他們（他們也會繞過派派鼠）。前院柵欄裡的花草、大蘑菇、青苔石跟家具一樣可以搬、可以收進收藏冊。地勢：房子和前院是平的，往北（神木那邊）漸漸變高，溪水從高處流下來、沿途有好幾個小瀑布，神木後面是山，兩側遠處有小丘。遠方是一圈手繪的遠山和樹林剪影；神木的板根有順著根長的樹皮溝紋。在家裡點地板或前院的地面，派派鼠就走過去（會繞過家具、菜園、柵欄，要出門會開門）；沒人操作時，派派鼠會自己在屋裡用家具、出門逛前院、看胡蘿蔔、去溪邊，偶爾自言自語。
開場說完話後跳出操作說明，按「開始玩！」大家才開始動。第一個任務（嘿！新來的）做完以前，派派狼和派派兔都站在門口的小石路上等派派鼠回應（偶爾轉頭看派派鼠）；做完以後才是自由模式：他們會在派派鼠家的前院走走，或去做喜歡的事（澆水、釣魚）。

**觀賞時間**：玩家一段時間（約 12 秒）沒有動滑鼠或鍵盤時，鏡頭會慢慢跟著派派鼠，看牠自己在家裡和前院跟家具互動（坐椅子、看書、睡覺、閒晃）；這是一個看派派鼠過生活的療癒遊戲。玩家一動，鏡頭就停在原地交還給玩家。地面都有手作感的質地：一根一根的小草、帶小石子的泥土、會流動閃光的溪水、屋裡一圈一圈辮子編的圓地毯。
派派鼠剛搬來時右手提著一個大皮箱。開場結束後，派派狼和派派兔平常站在門口的小石路上；過一陣子派派兔會拿澆水壺去胡蘿蔔園澆水，派派狼會去溪畔釣魚角坐著釣魚（偶爾釣到小鞋子），做完再回門口。胡蘿蔔園、溪畔釣魚角可以出現在故事和任務裡，但先不做成家具。

互動：坐（椅子、沙發）、睡（床）、看書（書櫃）；訪客會到胡蘿蔔園澆水、到溪畔釣魚；派派鼠會到信箱取信、翻相簿。
